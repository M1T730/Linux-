# Alerts with and Grafana built-in alerts

**In Summary:**\
Created basic grafana built-in alerts based on prometheus metrics, sending alerts to a discord server.

**in particular:**
* Node DOWN (CRITICAL)( 5 minutes)
* High CPU  (CRITICAL)( above 80% for 10 minutes )
* High RAM  (WARNING)( above 80% for 10 minutes )
* High Disk (WARNING)( above 80% for 10 minutes )
* Critical Temp (CRITICAL) (above 90 degreees for 2 minutes )
* Warning Temp  (Warning) (above 75 degreees for 10 minutes )
* High I/O wait (Warning) (above 20% for 10 minutes )
* Network Rx Errors (Warning) (above 1 for 10 minutes )
* Network Tx Errors (Warning) (above 1 for 10 minutes )
* Inode usage (Warning) (above 90% for 10 minutes )
